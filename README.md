# SmartCart Customer Segmentation System

## Project Overview

This project uses K-Means Clustering to segment SmartCart customers into meaningful groups based on spending behaviour, purchase frequency, website activity, and engagement patterns.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Algorithm

- K-Means Clustering
- Elbow Method

## Features

- Data Cleaning
- Feature Encoding
- Feature Scaling
- Elbow Method
- Customer Segmentation
- Cluster Analysis
- Business Insights

## Business Benefits

- Personalized Marketing
- Customer Retention
- Better Customer Understanding
- Revenue Optimization
